# The Illusion of Uniqueness: Iris Recognition in Twin Subjects

This repository contains the code used for the project **"The Illusion of Uniqueness: Iris Recognition in Twin Subjects"**.

The project evaluates iris recognition on twin subjects through a complete biometric pipeline:

1. dataset audit and metadata extraction
2. duplicate removal
3. image quality audit
4. Daugman-style iris segmentation
5. strict segmentation filtering
6. Rubber Sheet normalization
7. conservative masking
8. Gabor-style binary feature extraction
9. masked Hamming Distance matching with angular shift compensation
10. verification analysis
11. statistical analysis of twin similarity
12. additional LBP and Blob/LoG texture analysis
13. closed-set identification
14. failure analysis

The main goal is to understand whether twin iris comparisons behave differently from standard unrelated impostor comparisons.

## Dataset format

The raw dataset is expected to be organized by family. Each family contains four folders:

```text
CASIA-Iris-Twins/
├── 00/
│   ├── 1L/
│   ├── 1R/
│   ├── 2L/
│   └── 2R/
├── 01/
│   ├── 1L/
│   ├── 1R/
│   ├── 2L/
│   └── 2R/
...
```

The meaning of each folder is:

```text
1L = twin 1, left eye
1R = twin 1, right eye
2L = twin 2, left eye
2R = twin 2, right eye
```

The code expects CASIA-like filenames, for example:

```text
S3001L01.jpg
```

where the filename encodes family, twin index, eye side, and image index.

## How to run the full pipeline

The easiest way is to use the pipeline runner:

```bash
python scripts/run_pipeline.py --raw-root /absolute/path/to/CASIA-Iris-Twins
```

Example:

```bash
python scripts/run_pipeline.py --raw-root "/Users/yourname/Desktop/CASIA-Iris-Twins"
```

The runner executes only the scripts used for the final project pipeline and reproduces the intermediate data, plots, and summary files used in the report.

To see the commands without running them:

```bash
python scripts/run_pipeline.py --raw-root /absolute/path/to/CASIA-Iris-Twins --dry-run
```

To start from a specific stage:

```bash
python scripts/run_pipeline.py --raw-root /absolute/path/to/CASIA-Iris-Twins --start-at normalize_daugman_strict_v3
```

To stop after a specific stage:

```bash
python scripts/run_pipeline.py --raw-root /absolute/path/to/CASIA-Iris-Twins --stop-after match_gabor_codes
```

The full pipeline can also be run manually.

Important note: some early scripts use the historical relative path `iris_twins_project/data/...`. For this reason, the safest manual setup is:

```bash

```

## Main final results

The final experiment used the Daugman-style strict subset:

```text
Accepted images: 1465
Families: 99
Iris identities: 313
Selected matching pairs: 63,389
```

Verification results:

```text
Unrelated impostors EER: 7.55%
Twin same-eye impostors EER: 11.39%
All impostors EER: 8.17%
```

Closed-set identification results:

```text
Gallery templates: 313
Probe templates: 1152
Rank-1 Recognition Rate: 82.64%
CMS@20: 91.58%
Rank-1 errors caused by twins: 9 / 200
```

The main conclusion is that iris recognition remains effective in twin subjects, but twin comparisons are a more challenging impostor condition than unrelated comparisons.

## What should be committed to GitHub?

Do **not** commit raw or derived biometric images.

Keep the repository mainly code-based:

```text
scripts/
requirements.txt
README.md
.gitignore
```

Optional lightweight reproducibility files can be placed in a separate folder such as:

```text
results/final/
```

Recommended files to keep:

```text
results/final/quality_summary.json
results/final/segmentation_daugman_summary.json
results/final/normalization_daugman_strict_v3_summary.json
results/final/features_summary.json
results/final/pairs_features_summary.json
results/final/matching_summary.json
results/final/lbp_blob_relation_stats.csv
results/final/closed_set_summary.json
results/final/failure_analysis_summary.json
results/final/plots/*.png
```

Avoid committing:

```text
data/raw/

data/segmentation_daugman/contact_sheets/
data/normalized/daugman_strict_v3/images/
data/normalized/daugman_strict_v3/masks/

data/normalized/daugman_strict_v3/contact_sheets/
```
